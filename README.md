Digital Hubert Vision (DHV)

A simple Login and Registration application developed with Flutter and Dart as a mobile application development class exercise.

About the Project

Digital Hubert Vision (DHV) is a basic authentication interface designed to demonstrate the fundamental concepts of Flutter development.

The application provides two screens in one interface: Login and Register. Users can switch between the two forms using a button.

Features

- Simple and clean user interface.
- Custom DVH text-based logo.
- Login form.
- Registration form.
- Full Name input field for registration.
- Email input field.
- Password input field.
- Switch between Login and Register.
- Responsive layout.

Technologies Used

- Flutter: UI framework.
- Dart: Programming language.
- Visual Studio Code: Code editor.
- Chrome / Microsoft Edge: Web testing browsers.

Installation and Setup

1. Install Flutter SDK.
2. Install Visual Studio Code.
3. Install the Flutter and Dart extensions.
4. Clone this repository:

git clone YOUR_GITHUB_REPOSITORY_URL

5. Open the project folder in VS Code.
6. Install dependencies:

flutter pub get

7. Run the application on Chrome:

flutter run -d chrome

Or run it on Microsoft Edge:

flutter run -d edge
